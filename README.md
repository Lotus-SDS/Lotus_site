# Lotus

Site da Lotus ([lotusdev.com.br](https://lotusdev.com.br)) em React + Vite + Tailwind.

## Desenvolvimento

```bash
git clone https://github.com/Lotus-SDS/Lotus_site.git
npm install
npm run dev
```

`npm run lint` e `npm run build` são os mesmos passos que o CI roda em todo PR. O build sai em `dist/`.
